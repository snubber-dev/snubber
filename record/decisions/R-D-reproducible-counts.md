# R-D-reproducible-counts — Must a measured count reproduce from a stated command

**Status.** `open`
**Opened.** 2026-08-23
**Settles when.** It is stated whether an Evidence carrying a measured count must name the command that reproduces it, and what a reader does when re-running it disagrees.

## Question

An Evidence graded `measured` states a number the record vouches for. If nothing states how
the number was produced, the vouching is exactly the unwatched claim this project exists to
catch, sitting in the one type that is never edited. The thesis pointed at Evidence itself: measurement forces decisions, so an unreproducible measurement is moved ground that
nothing can re-check.

The tension is real on both sides. Requiring a source command makes `measured` mean
re-runnable and gives drift a detector — re-run and compare. But a command is a claim too:
it goes stale with the tree it ran against, a re-run that disagrees may mean the world moved
rather than the entry was wrong, and R-D-recorded-dates-the-recording already accepts that
the record vouches for when it learned, not for the world holding still. Whether
disagreement reopens the consumer, supersedes the Evidence, or merely dates it is the half
no rule can answer.

This returns with the first Evidence that carries a count.
